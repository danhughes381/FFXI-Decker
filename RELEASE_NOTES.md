# Decker v1.47

**Enhanced In-Game Macro Interface for Final Fantasy XI** — by Mutant X.

## Features

- Both Ctrl and Alt macro rows visible together (20 macros).
- Keyboard navigation, configurable row-switch key, and direct macro bindings.
- Opacity and auto-hide, including a 2-second option.
- Manual macro-book selector (experimental).
- Optional red-text recast indicators with manual action mapping (experimental).
- Escape should not change navigation lock state.
- Simplified eight-step first-time setup guide.

## Testing status

v1.47 is the latest packaged build. Startup arrow navigation, 2-second auto-hide, and cooldown detection have not all been independently confirmed in-game. Treat this as a development release.

## Install

Download the v1.47 ZIP, extract `addons/decker` into your Ashita addons directory, then load Decker through Ashita. See README.md for first-time setup.
